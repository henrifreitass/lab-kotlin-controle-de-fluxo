# Lab Kotlin: Controle de Fluxo

Exercícios de laboratório sobre estruturas de repetição, condicionais e
'break' / 'continue' em Kotlin.

Feito por Henrique

## Exercícios

| # | Nome | O que faz |
|---|------|-----------|
| 01 | Filtro de vogais | Imprime só as consoantes de "Universidade" |
| 02 | Primeiro múltiplo comum | Acha o primeiro número divisível por 7 e 13 |
| 03 | Somador com limite | Soma de 1 a 100, pulando múltiplos de 10 e parando se passar de 500 |
| 04 | Caixa eletrônico | Saques de R$ 150 até o saldo acabar |
| 05 | Números primos | Verifica se um número é primo |
| 06 | Menu teimoso | Menu que simula opções e encerra no 0 |
| 07 | Pula-obstáculos | Imprime de 1 a 50 sem os terminados em 7 |
| 08 | Cofre | Senha com 5 tentativas e trava na terceira errada |

## Como rodar

1. Abra o projeto no IntelliJ IDEA
2. Abra o arquivo do exercício que quiser
3. Clique no botão ▶ ao lado do 'main'
